# Chapter 24 — Production Checklist

**Starting state:** anything. This chapter measures what you have.

**What this chapter builds:** an honest score for your installation, and
the handover document for whoever inherits it.

```bash
./audit-hardening.sh          # your lab will fail several. That is correct.
cat docs/handover-template.md
```

Every check in `audit-hardening.sh` corresponds to an outage described
somewhere in this book. Read each failure rather than adjusting the script.
