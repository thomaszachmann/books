# VPN-Zugang (Lab GmbH, fiktiv)

Der VPN-Zugang erfolgt über WireGuard. Neue Zugänge beantragst du im Portal
unter "IT-Services > Netzwerk". Die Freigabe dauert in der Regel zwei Werktage.

Schlüssel werden alle 90 Tage rotiert. Bei Verlust eines Laptops sperrt der
Service Desk den Schlüssel sofort, Telefon intern 4711.
