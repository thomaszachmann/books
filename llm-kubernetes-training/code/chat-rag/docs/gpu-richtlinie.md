# Richtlinie GPU-Nutzung im KI-Cluster (Lab GmbH, fiktiv)

Der GPU-Node rke2-gpu-1 ist für Inferenz reserviert. Trainingsjobs und
Fine-Tuning laufen ausschließlich nach Freigabe durch das Plattform-Team.

Jedes Team erhält einen eigenen LiteLLM Virtual Key mit Monatsbudget. Das
Standardbudget beträgt 50 Euro pro Monat, Erhöhungen beantragt die Teamleitung.

Personenbezogene Daten dürfen nur in Modelle gegeben werden, die im eigenen
Rechenzentrum laufen. Der Fallback auf externe APIs ist für solche Daten gesperrt.
