# Bereitschaftsregelung Plattform-Team (Lab GmbH, fiktiv)

Die Rufbereitschaft wechselt jeden Montag um 09:00 Uhr. Die Übergabe erfolgt im
Kanal #plattform-oncall mit einer kurzen Liste offener Incidents.

Reaktionszeit in der Bereitschaft: 15 Minuten für P1, 60 Minuten für P2.
P3-Tickets werden erst am nächsten Arbeitstag bearbeitet.

Für jede angefangene Bereitschaftswoche gibt es eine Pauschale von 350 Euro.
Einsätze außerhalb der Kernzeit werden zusätzlich als Arbeitszeit erfasst.
